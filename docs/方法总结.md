# FOLoRA 方法总结（中文）

> 面向复试讲解：**一句话讲清「做了什么、为什么、凭什么」**。

## 一句话定位

在「用 LoRA 做持续学习」这个场景下，**灾难性遗忘的根源是低秩子空间被新任务反复覆盖**。我们提出 **FOLoRA**：用二阶 Fisher 信息衡量「哪些方向对老任务重要」，然后**按重要性加权地保护这些方向**——重要的方向强保护（防遗忘）、次要的方向允许复用（保塑性）。配一条可推导的遗忘上界，方法不是拍脑袋、而是从界里"推"出来的。

## 背景：为什么 PEFT 也会遗忘

- LoRA 冻结主干，只学低秩增量 `ΔW = BA`（秩 r），参数极少。
- 但串行学多个任务时，同一个低秩子空间被不断改写，老任务依赖的特征结构被破坏 → 遗忘。
- 已有方法的问题：
  - **O-LoRA**（正交子空间）：把新任务 adapter 初始化到与老任务正交的子空间，但**等权保护所有方向**，过度约束、浪费秩；
  - **EWC-LoRA**（对角 Fisher）：逐参数惩罚，**忽略低秩结构**；
  - 它们的共同盲点：**不区分方向的重要性**。

## 核心思想（一句话）

**遗忘 ≈ 新更新与「老任务的高曲率方向」的重叠**；所以保护方向应该**按 Fisher 信息（曲率）加权**，而不是等权。

## 方法三步

1. **估重要性**（每任务结束后）：用当前任务数据估计每层**参数 Fisher 核**
   `F = E[g_θ g_θᵀ]`，其中 `g_θ = ∂L/∂θ` 是损失对 LoRA 参数 θ=(A,B) 的梯度。这个核
   刻画了「哪些参数方向对当前任务重要」。
   > 关键实现点 1：必须用**逐样本梯度** `E[g_s g_sᵀ]`（Fisher 的二阶矩），不能用均值
   > 梯度外积——均值梯度接近收敛时退化为 0，会低估重要性。
   > 关键实现点 2：Fisher 用**参数梯度** g_θ 而非输出梯度 g_δ。遗忘上界是
   > `δθᵀ F_θ δθ`（参数 Fisher），输出方向 Fisher 会把输入 x 积分掉、保护方向与真实
   > 遗忘方向不对齐（v1 曾踩坑：输出 Fisher 正则形同失效，v2 改参数 Fisher 才起效）。

2. **建保护子空间**：把各任务的 Fisher 累加 `F̄ = Σ F`，做特征分解，取 top-k 特征方向
   `{σ_j, u_j}`（σ_j 是特征值 = 重要性），在**参数空间**内。

3. **软正交正则**：训练新任务时加正则
   `Ω = λ Σ_j σ_j ‖u_jᵀ δθ‖²`，其中 **δθ = θ − θ_ref 是「参数变化量」**
   （θ_ref 为上一个任务结束时的参数快照）。
   即「惩罚本任务带来的参数位移 δθ 在高重要性方向 u_j 上的投影」，**按 σ_j 加权**。
   > 关键实现点：必须惩罚**变化量 δθ**，不能惩罚**绝对量 θ**。任务一开始 δθ=0、
   > 正则自然为零，老任务的已有对齐被保留，只约束"新的移动"；若惩罚绝对量 θ，
   > 任务一开始 reg 就 >0，会把老任务已学到的方向一起往外推，等于主动抹掉老知识
   > （实测会让 FOLoRA 退化到比朴素 seq 还差）。这与 EWC 的 `(θ−θ*)²` 惩罚变化量同理。

## 数学推导主线（论文 §4/§5）

1. 二阶泰勒：`L_τ(θ+δ) ≈ L_τ(θ) + ∇L_τ·δ + ½ δᵀ F_τ δ`，收敛点 `∇L_τ≈0` → **遗忘 ≈ ½ δᵀ F_τ δ**。
2. 累加所有老任务：`遗忘 ≤ ½ δᵀ Ḡ δ = ½ Σ_j σ_j (u_jᵀ δ)²`（特征分解）。
3. FOLoRA 的正则项 `Ω = Σ_j σ_j ‖u_jᵀ δθ‖²` **正好最小化这个上界的主导项**——所以方法是"从界推导出来"的。
4. 当 σ_j 全为 1 时退化为等权正交（O-LoRA 的特例），说明 FOLoRA 是更一般的推广。

## 为什么这能发 CCF-C（创新点 + 与已有工作的区别）

| 方法 | 保护什么 | 是否按重要性加权 | 参数预算 |
|---|---|---|---|
| EWC-LoRA | 逐参数 | 对角 Fisher（忽略低秩结构） | 固定 |
| O-LoRA | 权重子空间 | ❌ 等权 | **每任务增长** |
| FOLoRA | **参数方向子空间** | ✅ **Fisher 特征值加权** | **固定** |

三个可讲的区别点：**① 重要性加权（vs O-LoRA 等权）② 固定预算（vs O-LoRA 增长）③ 二阶子空间（vs EWC 逐参数）**。

## 实验（复现口径）

- 主干：ViT-B/16（ImageNet-1k 预训练，冻结），LoRA 注入 12 层 MLP 下投影（rank 16）。
- 基准：Split CIFAR-100（20 任务 × 5 类）、Split ImageNet-R（20 任务 × 10 类），类增量协议。
- 基线：Seq-LoRA / EWC-LoRA / O-LoRA / L2P / CODA-Prompt。
- 指标：最终平均准确率（avgACC）、平均遗忘（FGT）。adapter 方法 5 epoch（CIFAR-100 10 seed、ImageNet-R 5 seed），prompt 方法 20 epoch（各自最优，3 seed）。
- FOLoRA 默认配置：λ=300、k=16（网格搜索选定）。

| 方法 | CIFAR-100 acc/FGT | ImageNet-R acc/FGT |
|---|---|---|
| Seq-LoRA | 7.19 / 90.90 | 6.55 / 84.42 |
| EWC-LoRA | 9.17 / 88.76 | 8.17 / 82.92 |
| O-LoRA | 7.74 / 90.01 | 6.38 / 83.44 |
| L2P (20e) | 8.67 / 89.08 | 7.05 / 80.22 |
| CODA-Prompt (20e) | 9.35 / 88.52 | 6.93 / 79.54 |
| **FOLoRA** | **10.07 / 87.65** | **9.56 / 79.44** |

- FOLoRA 两个基准上都是最高准确率 + 最低遗忘（含 prompt 基线各自最优 20 epoch）。
  ImageNet-R：遗忘 −3.48pp（p<0.001）、准确率 +1.39pp（p=0.005）都显著；CIFAR-100：
  遗忘 −1.11pp（p=0.044，转显著）、准确率 +0.90pp（均值占优，p=0.110）。调优 EWC（λ=30）
  9.58 仍低 FOLoRA 0.49pp。
- 诚实口径：CIFAR-100 准确率仍不显著（方差大、近双峰），但遗忘已显著，核心「抗遗忘」
  主张两基准站得住。epoch 与家族交互：Fisher 方法要 5 epoch（过拟合退化 Fisher）、
  prompt 方法要 20 epoch（key 学习），各自最优下 FOLoRA 仍赢。

## 面试可能被问的点

- **"Fisher 为什么要逐样本？"** → 均值梯度接近收敛时趋 0，其外积会把重要性低估到零；Fisher 是二阶矩 E[g g²]，不随收敛消失。
- **"和 O-LoRA 的本质区别？"** → 等权 vs 重要性加权；每任务增长 vs 固定预算。
- **"显存/开销？"** → 冻结主干只训 LoRA（<0.5% 参数）；Fisher 核在参数空间（每层约
  r·(d_in+d_out) 维），不显式 materialize、只用 top-k（k=16）低秩近似，逐样本估计每任务几十秒。

# 答辩讲稿（浙大软院复试）

> 主线：**「非结构化 → 结构化信息抽取」×「参数高效微调」×「部署优化」三个项目**，
> 本项目（FOLoRA）是第三个，定位是**有算法创新、有数学推导、能发 CCF-C 论文**的科研项目。

## 1. 开场（30 秒定位）

"我的第三个项目是**参数高效微调在持续学习中的灾难性遗忘问题**，方法叫 FOLoRA，
已整理成 Neurocomputing（CCF-C）投稿论文。核心贡献是：**用二阶 Fisher 信息在低秩
子空间内做『重要性加权的正交投影』，并配套一条可推导的遗忘上界**。"

## 2. 问题（为什么要做）

- **背景**：大模型全量微调太贵 → 参数高效微调（LoRA）只训 0.5% 参数。
- **痛点**：LoRA 串行学多个任务时，**仍然会灾难性遗忘**——虽然参数少，但低秩子空间
  被反复覆盖，老任务依赖的特征结构被破坏。
- **一句话问题**：怎么让 LoRA 在持续学习里"记住旧的、学会新的"。

## 3. 方法（FOLoRA，三步）

1. **估重要性**：每个任务学完后，用**逐样本参数梯度** `g_θ = (g_A, g_B)`（损失对 LoRA
   参数 A、B 的梯度）估**参数 Fisher 核** `F = E[g_θ g_θᵀ]`，刻画哪些参数方向对当前
   任务重要。
2. **建保护子空间**：累加各任务 Fisher `F̄ = ΣF`，特征分解取 top-k 方向 `{σ_j, u_j}`
   （σ_j=特征值=重要性），得到参数空间的「重要方向」。
3. **软正交正则**：学新任务时加 `Ω = λ Σ σ_j ‖u_jᵀ δθ‖²`，其中 `δθ = θ − θ_ref`
   是**参数变化量**（θ_ref 是上一任务结束时的参数快照）——按重要性惩罚本任务带来的
   参数位移在高曲率方向上的投影。任务一开始 δθ=0、正则归零，只约束"新的移动"。

**一句话**：重要的方向强保护、次要的方向允许复用 → 稳定-塑性平衡。

> 关键点：Fisher 用**参数梯度** g_θ 而非输出梯度 g_δ——遗忘上界是 δθᵀ F_θ δθ（参数
> Fisher），输出方向 Fisher 会把输入 x 积分掉、保护方向与真实遗忘方向不对齐（实测
> 用输出 Fisher 时正则形同失效，这是 v1→v2 的关键修复）。

## 4. 数学推导（必背主线）

- 二阶泰勒：`L_τ(θ+δ) ≈ L_τ(θ) + ∇L_τ·δ + ½ δᵀ F_τ δ`，收敛点 `∇L_τ≈0`。
- 所以**遗忘 ≈ ½ δᵀ F_τ δ**（新位移与 Fisher 的二次型）。
- 累加老任务 → `遗忘 ≤ ½ Σ σ_j (u_jᵀ δ)²`。
- FOLoRA 正则项 `Ω = Σ σ_j ‖u_jᵀ δθ‖²` **正好最小化这个上界** → 方法从界里推导出来。

## 5. 创新点（与已有工作的三处区别）

| 对比 | 已有方法 | FOLoRA |
|---|---|---|
| 保护方式 | O-LoRA 等权正交子空间 | **Fisher 特征值加权** |
| 参数预算 | O-LoRA 每任务增长 | **固定预算（共享 adapter）** |
| 重要性估计 | EWC 对角（忽略低秩结构） | **低秩输出空间的二阶核** |

## 6. 实验（口径背熟）

- 主干：ViT-B/16（ImageNet-1k 预训练，冻结），LoRA rank16 注入 12 层 MLP 下投影。
- 基准：Split CIFAR-100（20×5）、Split ImageNet-R（20×10），类增量协议。
- 基线：Seq-LoRA / EWC-LoRA / O-LoRA / L2P / CODA-Prompt；指标：平均准确率（avgACC）、遗忘（FGT）；5 seed（L2P/CODA 为 3 seed）。
- FOLoRA 默认配置：λ=300、k=16（网格搜索选定）。

| 方法 | CIFAR-100 acc | CIFAR-100 FGT | ImageNet-R acc | ImageNet-R FGT |
|---|---|---|---|---|
| Seq-LoRA | 7.31±0.74 | 90.71±0.79 | 6.55±0.36 | 84.42±0.26 |
| EWC-LoRA | 9.40±0.94 | 88.45±1.03 | 8.17±0.75 | 82.92±0.95 |
| O-LoRA | 7.99±0.82 | 89.74±0.89 | 6.38±0.43 | 83.44±0.27 |
| L2P | 8.02±0.24 | 89.50±0.53 | 5.74±0.30 | 80.94±0.14 |
| CODA-Prompt | 8.04±0.46 | 89.79±0.84 | 5.96±0.43 | 80.93±0.66 |
| **FOLoRA** | **10.68±1.56** | **87.10±1.49** | **9.56±0.83** | **79.44±0.62** |

- FOLoRA 两个基准上都是最高准确率 + 最低遗忘。ImageNet-R 上遗忘比 EWC 显著降 3.48pp、
  准确率 +1.39pp；CIFAR-100 上均值反超（acc +1.28、FGT −1.35）。调优后的 EWC（λ=30）
  在 CIFAR-100 达 9.58，仍比 FOLoRA 低 1.10pp——坐实「不是基线没调好」。
- 诚实口径：ImageNet-R 显著（5 seed）、CIFAR-100 均值占优但 std 大、单点不显著（分布近
  双峰）；L2P/CODA 在 CIFAR-100 与 olora/seq 相当、在 ImageNet-R 低于 seq——类增量无
  task-id 时 prompt 靠冻结 ViT 的 [CLS] 特征做 key 匹配、该特征未适配下游、选择噪声大。

## 7. 预期问题 Q&A

- **"Fisher 为什么逐样本？"** 均值梯度接近收敛时趋 0，其外积把重要性低估到零；
  Fisher 是二阶矩 E[g g²]，不随收敛消失。
- **"正则为什么惩罚变化量 δθ 而不是绝对量 θ？"** 遗忘来自「新任务带来的位移」，
  所以应约束 `δθ = θ − θ_ref`（θ_ref 是上一任务参数快照）。任务一开始 δθ=0、正则归零，
  保留老任务已有的对齐；若惩罚绝对量 θ，任务一开始 reg 就 >0，会把老方向往外推、
  等于主动抹掉老知识。这与 EWC 惩罚 `(θ−θ*)²` 是同一个道理。
- **"和 O-LoRA 本质区别？"** 等权 vs 重要性加权；每任务增长 vs 固定预算。
- **"复杂度/开销？"** 冻结主干只训 <0.5% 参数；Fisher 核在参数空间（每层约
  r·(d_in+d_out) 维），不显式 materialize、只用 top-k（k=16）低秩近似，逐样本估计每任务几十秒，可忽略。
- **"为什么 LoRA 只注入 MLP 下投影？"** torchvision 的 MultiheadAttention 用函数式
  接口直接读 out_proj.weight，注入会被静默绕过；MLP 是普通 Linear 可正常包装。
- **"类增量 vs 任务增量？"** 主实验是类增量（推理时不知道任务 id，更难），任务增量
  作辅助指标。
